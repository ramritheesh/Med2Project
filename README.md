A modern healthcare web application that enables users to upload prescriptions, manage medications, receive dosage reminders, and locate nearby pharmacies through an intuitive and responsive interface.

---

## 📖 Overview

**MediCare** is designed to simplify medication management by providing a centralized platform where users can securely upload prescriptions, organize medicines, receive timely reminders, and browse pharmacy information.

The application focuses on improving accessibility, medication adherence, and user convenience through a clean and responsive user experience.

---

## ✨ Features

- 📄 Upload digital prescriptions

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/ramritheesh/Med2Pro.git
```

Go to the project folder

```bash
cd Med2Pro
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open your browser

```
http://localhost:5173
```
